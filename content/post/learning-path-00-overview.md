> 一份为「一个人也能打完全程」设计的 16 周教材：三个方向共用同一套底座技能，按阶段轮转主攻，每周有明确的学、练、交、验。
>
> 全系列共 8 篇，本页是总览与目录。

## 先说清楚：能给你什么、不能给你什么

**能给你**（约 120 小时 = 16 周 × 7.5 小时）：

- 一张完整地图：三方向各有什么题型/玩法、底层技能如何互相借用。
- 三条线都走到**入门偏中**：能独立解 CTF 的 misc/隐写/取证/古典密码/入门 OSINT；能单人完成一个小型 Puzzle Hunt；能拆解经典 ARG 的线索链并设计 mini 版。
- 一套能自己往前走的习惯：判断编码、写脚本、写复盘、卡住时怎么升级。

**不能给你**（诚实边界）：

- 「全面」＝每条线都学到专家级，在 120 小时里不可能。真正的全面需要之后 1–2 年的专项投入。
- 打 CTF 拿名次、啃下 pwn/kernel、独立破解现代密码学，这些不在本路径范围内（见下文「不覆盖清单」）。
- 保证 16 周按时完成。课业和日语课会挤时间，所以日程标了 ★/☆ 两档。

## 这套教材为谁写的

| 情况 | 教材里的对应 |
| --- | --- |
| 计科大一生，课业与日语（零基础）占时间 | 每周上限 5–10 小时；★/☆ 双轨 + 停摆周机制 |
| 命令行有点基础，Python 不熟 | 第 1–2 周集中补「够用版」Python，之后边做题边补 |
| 解谜仅停留在「玩过解谜游戏」 | 从题型识别与提取两个最小技能切入，不预设谜题背景 |
| Windows + 已有 WSL2 | 工具链以 WSL2 为主线，网页版工具优先 |
| 英文较弱但知道英文资源更好 | 中文导读 + 术语表 + 逐段翻译工作流，不做整站翻译 |
| 想单人挑战，也不排斥线上比赛 | 练习阶梯全部标 `[S]/[T]/[R]`，主线只保留 solo 项 |

## 使用规则（只有四条）

1. **一周一页**：每周只打开当周模块，不用通读全部教材。
2. **先做题再补理论**：每个知识点的入口都是一道题；理论只在卡住时回查。
3. **每周交一份东西**：速记 writeup 也算，空周不算完成。
4. **掉队就只做 ★**：☆ 周可以整周跳过，不影响闭环。

## 三线共享技能底座

ARG、CTF、Puzzle Hunt 表面是三件事，实际 70% 底层能力重合。**底座打通后，三条线只是应用场景不同。**

| 底座能力 | CTF 里 | Puzzle Hunt 里 | ARG 里 |
| --- | --- | --- | --- |
| 命令行与脚本化 | `file/strings/binwalk` 流水线 | 批量试词、生成候选 | 抓页面、批量验证 |
| Python 够用版 | 解码、爆破、写 solver | 提取答案、枚举 | 批量请求、频次统计 |
| 编码与数制 | base64/hex/URL/Unicode/摩斯 | 同上，更偏「藏」 | 藏在网页/文件名里 |
| 文本变换与古典密码 | ROT/Vigenère/替换/换位 | 词谜、枚举、答案格式 | 隐藏口令 |
| 文件与载体分析 | 图片/音频/压缩包/流量 | 图片题、网格题 | 频谱、视频帧、元数据 |
| 检索与信息收集 | OSINT、whois、快照 | 查工具、查变体 | 跨媒介溯源 |
| 结构与提取 | 题型识别、答案格式 | **核心**：extraction | 线索链与兔子洞设计 |
| 叙事与推理 | 题干暗示 | 题面文字本身是线索 | 剧情推进 |

## 16 周日程

不做三条平行进度条，而是**每阶段一个主模块，其余两线每周 1–1.5 小时保温**：

- W1–2 基础底座（三线共用）
- W3–6 CTF 主攻（60%）+ Puzzle Hunt 保温（20%）+ 底座复习（20%）
- W7–9 Puzzle Hunt 主攻（60%）+ CTF 保温（20%）+ 底座复习（20%）
- W10–12 ARG 主攻（60%）+ CTF 保温（20%）+ Puzzle Hunt 保温（20%）
- W13–16 单飞综合：比赛 / 档案 / 创作

**为什么是这个顺序**：CTF 在前，因为它的工具链（命令行、编码、文件分析）是另两线的底座；Puzzle Hunt 在中，核心是「结构 + 提取」，需要先有工具手感；ARG 在后，几乎要用到前面全部技能。

**标记含义**：`★` 必需（8 周构成可独立闭环）；`☆` 加成（掉队时可整周跳过）；`[S]` 单人可完成；`[T]` 需队友；`[R]` 需靶机/服务器。

| 周 | 标记 | 主模块 | 主题 | 交付物 |
| --- | --- | --- | --- | --- |
| W1 | ★ | 基础 | 环境打通 + CyberChef + Bandit 0–5 + 第一题（**免注册**） | 第一份 writeup |

**★ 最小闭环（8 周）**：W1 → W2 → W3 → W5 → W7 → W8 → W10 → W13。做完这 8 周，你已经走完「底座 → CTF 入门 → PH 完整一篇 → ARG 认知 → 真实比赛」的整圈。

## 每周固定节奏与硬约束

| 动作 | 时长 | 做什么 |
| --- | --- | --- |
| 学 | 2–3h | 读当周模块对应小节 + 一个最小示例 |
| 练 | 3–5h | 做当周练习阶梯；卡住按三级升级策略处理 |
| 复盘 | 1h | 写当周交付物；更新打卡表；往错题本记 1 条 |

- 每周最多引入 **3 个新工具**；
- 同一题卡 **90 分钟**必须升级（自查 → 官方提示 → 看 writeup 后重做 → 归档超纲）；
- **每周 20 分钟回看**：翻错题本新增条目 + 重做上周 1 道题；
- 连续停摆 3 周 → 只保留 ★ 周，16 周变 8 周闭环。

## 本路径明确不覆盖

以下内容不在 16 周范围内，遇到就记下来、跳过，**不要拿它评估自己**：

| 不覆盖 | 为什么 | 什么时候再回来 |
| --- | --- | --- |
| pwn（栈/堆利用、ROP、kernel） | 需要大量调试时间与专门环境 | 第二年，或学完「系统安全」课之后 |
| 高级 Web（复杂逻辑漏洞、云安全、SSRF 链） | 需要靶场与长期经验积累 | 学完 Web 安全基础课之后 |
| 密码学深水区（格攻击、ECC 深层、ZKP） | 数学门槛高 | 有兴趣时从 CryptoHack 的 Modular/Public-Key 课程切入 |
| 大型逆向（VMP、恶意代码分析） | 需要长期工具训练 | 有明确方向后 |
| 硬件/IoT/无线电 | 需要设备 | 不计划 |

> 碰到这些题的唯一正确动作：**标记「超纲」→ 跳过 → 记进错题本**。

## 第 1 天怎么开始（免注册，60–90 分钟）

1. **确认 WSL2**：Windows 终端执行 `wsl -l -v`，看到 Ubuntu 且 `VERSION` 为 2 即可。
2. **进 Linux**：执行 `wsl`，再执行 `python3 --version`。
3. **建工作区**：`mkdir -p ~/ctf/{notes,writeups,work,tools}`。
4. **网页版 CyberChef**：打开 [CyberChef](https://gchq.github.io/CyberChef/)，把 `aGVsbG8=` 粘进 Input，右侧选 `From Base64`，确认输出 `hello`。
5. **零注册实战**：`ssh bandit0@bandit.labs.overthewire.org -p 2220`（密码 `bandit0`），依次过 Bandit 0→5。
6. **写第一份 writeup**：5 行即可，存 `~/ctf/writeups/w1-bandit.md`。

完成标准：能说出「CyberChef 里我做了什么变换」+「Bandit 每关卡在哪一步、怎么过的」。
